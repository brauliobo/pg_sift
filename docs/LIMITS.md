# Limits

Generated by `scripts/gen-limits.sh` from `SIFT_LIMITS` in `src/core/limits.h`; do not edit by hand.
"Normal plan" means PostgreSQL executes its native plan with identical results (`sift.explain_why()` names the slug). PostgreSQL limits (1 GB per datum, 1,600 columns) also apply.
In testing builds (`SIFT_TESTING=1`), `SET sift.test_limits = 'id=value,...'` lowers hooked limits and `sift._test_limits()` lists all limits and active values.
