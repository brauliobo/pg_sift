# Messages: every NOTICE, WARNING and INFO of pg_sift

Generated by `scripts/gen-messages.sh` from `docs/messages.tsv`; do not edit by hand. `scripts/gen-messages.sh --check` (lint) fails when a message of `src/` or `sql/` has no row, when a row names a message that no longer exists, when the DETAIL or HINT of a row differs from the source, and when a number of a row is in none of the measurements it cites.

pg_sift tells what it chose on its own and what it advises, in the message levels the client shows by default: **41 NOTICE**, **11 WARNING** and **8 INFO** (the lines `VACUUM VERBOSE` adds). Every message has one row below: the exact text (`%s`, `%d`, `%u`, `%.0f` are the values it fills in), where and when it appears, the decision pg_sift took, the benefit and the trade-off of that decision with a measured number, and how to change it or switch it off. A cell that says *no measured number yet* is a measurement nobody made yet.

- `SET client_min_messages = warning` hides the NOTICEs and the INFO lines for the session; the choice they report is made either way. `ALTER DATABASE .. SET client_min_messages = warning` or `ALTER ROLE` keeps it.
- `CREATE INDEX` and `REINDEX` of a `sift_col` index print ONE NOTICE for all the choices they made, the advice and the limits they reached: the count, the values on two lines, and a HINT that names `SELECT * FROM sift.index_choices('index')`. That function returns one row of this page for each choice (the **CHOICE**, **ADVICE** and **LIMIT** rows below): its value on the index, the cost measured on it, the reason and the command that turns it off. `SELECT * FROM sift.help('slug')` returns any row of this page by its anchor, and `sift.help()` all of them.
- The DETAIL and HINT of a message are listed in full [at the end](#detail-and-hint-in-full). An ERROR with its HINT is not in this table: the refusals of the aggregate scan are in [USAGE](USAGE.md#why-a-query-kept-the-normal-plan) and the limits in [LIMITS](LIMITS.md). LOG and DEBUG messages go to the server log, not to the client, and are not listed.
- Numbers are in the units of their source: instructions of one backend, milliseconds, bytes, percent of the index; the conditions (rows, columns, version) are in the cited option case of [OPTIONS](OPTIONS.md).

## DETAIL and HINT in full

The text after the message line, as `psql` prints it (`%s`, `%d` fill in values). A DETAIL or HINT built from pieces at run time shows its fixed sentences.

- **index-choices-summary** (NOTICE)
  - HINT: Reasons, costs and how to turn each off: SELECT * FROM sift.index_choices('%s');
- **index-format-minor** (NOTICE)
  - HINT: SET sift.col_format_minor = 14 before the build to write a format the older library reads.
- **track-changes-minor** (NOTICE)
  - HINT: Raise sift.col_format_minor to 15 or more to track changes, or write WITH (track_changes = 'off').
- **string-overflow** (NOTICE)
  - HINT: Index an expression that keeps the part of the value that is used, such as left(column, 255).
- **auto-merge-autovacuum-off** (NOTICE)
  - DETAIL: The units answer from their pre-aggregates again only after a VACUUM of the table, and the merge of the index follows that VACUUM.
  - HINT: Run VACUUM on it from a job, or RESET autovacuum_enabled.
- **rewrite-chose-again** (NOTICE)
  - DETAIL: Rows appended since the build change what the defaults choose; an option you wrote is never changed.
  - HINT: ALTER INDEX %s SET (key_cut = 'off') keeps a choice off, and the same for the other options.
- **maintenance-failed** (WARNING)
  - DETAIL: It is retried later, after a growing delay.
- **write-buffer-stays-open** (WARNING)
  - DETAIL: The last maintenance step failed: %s
  - HINT: Run sift.merge() on the index, and read sift.workers for what the background did.
- **analyzer-options-changed** (WARNING)
  - DETAIL: Queries and inserts on its table fail until the index is rebuilt with REINDEX.
  - HINT: For no downtime, CREATE INDEX CONCURRENTLY a new index with the options, then drop this one.
- **siftagg-not-used** (NOTICE)
  - DETAIL: arm: %s
- **lookup-not-shared** (NOTICE)
  - HINT: Free dynamic shared memory (the size of /dev/shm), or SET sift.agg_lookup_shared_kb = 0.
- **upgrade-reindex-text** (WARNING)
  - HINT: Such words were cut at 255 bytes, and the index does not say whether it holds one, so every text index (analyzer other than keyword) is listed. REINDEX CONCURRENTLY cannot run in a transaction block. SELECT * FROM sift.upgrade_commands() lists them again.
- **upgrade-reindex-column** (WARNING)
  - HINT: The older units stay readable until then. REINDEX CONCURRENTLY cannot run in a transaction block. SELECT * FROM sift.upgrade_commands() gives the reason for each index.
- **upgrade-rewrite-table** (WARNING)
  - HINT: The older segments stay readable until then. VACUUM FULL takes an ACCESS EXCLUSIVE lock and rewrites the table: schedule it. SELECT * FROM sift.upgrade_commands() gives the reason for each table.
- **track-changes-ctid-queue-memory** (NOTICE)
  - HINT: Before a huge UPDATE or DELETE: ALTER INDEX %s SET (track_changes = 'off'), then 'ctid' again.
- **track-changes-concurrent** (NOTICE)
  - HINT: Run REINDEX INDEX %s without CONCURRENTLY to make the log complete.
- **track-changes-key-pending** (NOTICE)
  - DETAIL: Reads check the heap until the table has a UNIQUE or PRIMARY KEY constraint on the column alone, and a row written before that is not in the log, so the log stays incomplete after it.
  - HINT: REINDEX INDEX %s gives it a baseline once the constraint exists.
