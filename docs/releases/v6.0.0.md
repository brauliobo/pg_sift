pg_sift 6.0.0: Format Major 2 for `sift_col` and `sift_table`, a vectorized aggregate engine, a 63-option configuration surface and a consolidated `sift.*` API, with every 5.x index and table still readable and writable.

## What 6.0 changes for you

Nothing is rebuilt at the upgrade: an index or table of 5.x keeps its files and its answers. New indexes, new tables and every `REINDEX` write Format Major 2, which is smaller and faster to scan. Run `SELECT * FROM sift.upgrade_check();` on 5.1 first; it lists the removed settings and options a role, a dump or a script still names.

**To upgrade from 5.1 (any patch release)**
1. Run `psql -d mydb -f sql/pg_sift_upgrade_check.sql` on the 5.1 database and resolve every `blocker` row.
2. Install the 6.0 package and restart the server.
3. Run `ALTER EXTENSION pg_sift UPDATE TO '6.0';` in each database.
4. Optional, online, one relation at a time: `REINDEX INDEX CONCURRENTLY <idx>;` for a `sift_col` index and `SELECT sift.upgrade_table('<t>');` for a `sift_table`.

The format of a `sift` BM25 index is unchanged. [docs/UPGRADING.md](../UPGRADING.md) has the full checklist, the removed settings and the format table.

## What is new

- **Format Major 2:** unified storage for `sift_col` and `sift_table` with two-tier adaptive compression, key-order pruning, pre-aggregates and background maintenance ([ARCHITECTURE](../ARCHITECTURE.md), [TABLES](../TABLES.md)).
- **`SiftAgg`:** a 2,048-row SIMD-vectorized executor with fused pipelines, star joins, windows, Top-N and CTE streams; parallel scans are on by default ([ANALYTICS](../ANALYTICS.md)).
- **Search:** exact BM25 ranking, hybrid scans with structured filters, facets and scored aggregates ([SEARCH](../SEARCH.md)).
- **Operations:** tiering, TTL, projections, a lock escalation path for row locks and a memory budget per backend ([OPERATIONS](../OPERATIONS.md)).
- **Configuration:** 27 settings and the index and table options, each in [OPTIONS](../OPTIONS.md); removed ones are accepted and ignored with a notice.

## Compatibility

PostgreSQL 17, 18 and 19 on Linux x86_64 and aarch64; the SQLite and MariaDB extensions are released with it. Release history before 6.0 is in [CHANGELOG.md](../../CHANGELOG.md) and the notes next to this one.
