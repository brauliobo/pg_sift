# Options: the case for each default and opt-in

Every `WITH (...)` option of the index kinds and every `sift.*` setting, with its class and the measured case behind it. The table below is generated by
`scripts/gen-options.sh` from `docs/options.tsv` (the record) and the C sources (name, type, default, range): edit the record, never the table. The reference tables
with range, context and description are in [USAGE.md](USAGE.md#maintenance-and-operations); the one-line version is in the README ("Options at a glance").

A **default** is automatic behaviour: the build or the planner decides and a NOTICE at `CREATE INDEX` says what and how to opt out. It is on when it passes the rule of the 3.3 release:
at least 5% gain on a relevant class of queries, at most 3% index growth and at most 5% write cost. An **opt-in** failed one of those limits (or changes results, needs hardware,
takes memory, or has not run on real workloads) and is kept for the workloads where the win is clear; its `why` names the limit, and its gain, growth and write cost are the measured price.
A cell that reads **not measured** is a measurement the owning work still owes: `scripts/gen-options.sh --missing` lists them.

Gain, growth and write cost carry their conditions (rows, columns, version); `-` means the option has no such effect. PR is the pull request that introduced or last changed the behaviour;
Bench is a case of `bench/cases.tsv` or a file of stored results.
